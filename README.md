# منصة وادي عدي

دراسة تطوير وإعادة تأهيل وادي عدي بمحافظة مسقط. تتضمن النصوص والصور المستعادة من نسخة 12 أكتوبر 2026، وشعارَي بلدية مسقط ومحافظة مسقط في الصفحة الرئيسية، وأيقونة تثبيت «وادي عدي» للتطبيق.

## التشغيل

الخادم على Cloudflare Workers، والبيانات والحسابات والملفات في D1 ضمن خطة Workers Free. تعليمات الإنشاء والتهيئة الأولى في [DEPLOY-CLOUDFLARE.md](DEPLOY-CLOUDFLARE.md). تُعرض الدراسة للزائر دون دخول، فيما تقتصر عمليات الإضافة والتعديل والحذف والرفع وإدارة الأعضاء على الصلاحيات التي يتحقق منها الخادم. السجلات تحفظ تلقائيًا بعد كتابة العنوان والتفاصيل؛ رفع المرفقات يتم عند الضغط على حفظ.

حساب الأدمن الأول هو `ساميه الرواحي`، ويُنشأ فقط عبر تهيئة خادم محمية بسر خاص. رمزه الأولي `1234` ويجب تغييره إلى رمز أطول عند أول دخول قبل إجراء أي تعديل. الأعضاء الذين تضيفهم من المنصة يمرون بخطوة التغيير نفسها. لا تُحفظ كلمات المرور القديمة في النسخة الاحتياطية ولا يمكن استعادتها.

## التطوير

`npm run check` لفحص JavaScript، و`npm run build` لتجهيز الملفات الثابتة في `dist/`. لا تضع أسرار التهيئة أو بيانات حساب Cloudflare في المستودع. ملفات Firebase القديمة توثيق أرشيفي وغير مستخدمة في التطبيق الحالي.
